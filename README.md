# News Keyword Trend Analyzer

A full-stack application that aggregates data from NewsAPI and visualizes keyword trends through interactive charts.

## Live Demo

https://news-keyword-trend.vercel.app

> ⚠️ Backend is hosted on Render (free tier) and may take 10–20 seconds to spin up on first request.
> ⚠️ This project uses a free-tier NewsAPI key; daily request limits are in place and managed to ensure consistent functionality.

## Features

- Integrates with NewsAPI to aggregate real-time news data
- Keyword-based trend analysis
- Interactive data visualization using Chart.js
- Dynamic search functionality

## Tech Stack

- Frontend: React, Vite
- Backend: Node.js, Express
- Other: NewsAPI, Chart.js
